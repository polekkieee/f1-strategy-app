# 1. Expo Mobile as Primary Rig Companion

The repository contains both a legacy React web client (`frontend/`) and a modern Expo/React Native client (`mobile/`).

We decided to focus all active client development on the Expo mobile app and freeze the web client. Sim racers mount phones or tablets directly to their rigs, making a mobile companion screen the natural form factor for live AI Race Engineer calls and telemetry during a race.
